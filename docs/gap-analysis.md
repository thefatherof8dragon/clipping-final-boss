# Architectural Gap Analysis: Clipper vs PeakCut

Comparative audit between our current implementation (`clipper/`) and PeakCut (`studio/`, MIT License).

## Feature Matrix

| Feature | Ours (Status, Files & Evidence) | PeakCut (Status & Files) | Recommendation |
|---|---|---|---|
| **1. Live Recording** | **Works** (`clipper/live_engine.py:49-160`, `clipper/streamers.py:380-450`). Records live streams via ffmpeg pipe into 6s `.ts` chunks with continuous audio monitoring. Verified in `test_stage6_streamers.py`. | **Has** (`studio/live.py:120-240`). Spawns streamlink / yt-dlp recording subprocess with segmented output. | **Keep ours**: Ours uses native FFmpeg segmenting with sub-second loudness extraction; cleaner standalone architecture. |
| **2. Rolling Buffer** | **Works** (`clipper/live_engine.py:35-43, 160-220`). Implements 6-second MPEG-TS segments with CSV index tracking, 10-minute rolling retention, and 2 GB disk cap enforcement. | **Has** (`studio/live.py:300-380`). Rolling directory of `.ts` segments pruned by file mtime and disk threshold. | **Keep ours**: Well-integrated with our configuration and verified retention pruning. |
| **3. Spike Detection** | **Works** (`clipper/live_engine.py:375-430`, `clipper/candidate_picker.py`). Tracks unique active chatters via IRC `_NICK_REGEX` and rolling audio RMS loudness baseline (`mean + k*std`). Pre-roll (20s), post-roll (10s), cooldown (60s). | **Has** (`studio/live.py:400-510`). IRC chat monitor with keyword spike thresholds (`clip it`, lols, emote spikes). | **Keep ours**: Ours incorporates both unique-chatter counts and audio RMS loudness in one dynamic evaluator. |
| **4. Ranking with Score Breakdown** | **Works** (`clipper/ranker.py:15-110`). 5-factor scoring model (`0.30*hook + 0.25*chat + 0.20*emotion + 0.15*story + 0.10*trend`) with chat-less re-normalization, rank ordering, renaming, and human-readable "Why it ranked" generator. | **Partly** (`studio/brain.py:150-210`). Single composite score from LLM prompt or simple chat spike count. | **Keep ours**: Our 5-factor mathematical weighting is more nuanced and handles no-key mode without LLM token cost. |
| **5. Per-Clip Editor** | **Works** (`clipper/web/static/app.js:200-500`, `style.css:1260-1420`). 3-zone layout (tool rail, centered 9:16 preview, active drawer), word/line caption editor with 10 visual presets, trim sliders, aspect ratios (`9:16`, `1:1`, `4:5`, `16:9`). | **Has** (`web/index.html:1200-1550`, `studio/render.py`). Canvas preview scrubber with trim handles and caption style picker. | **Keep ours**: Our 10 ASS kinetic typography presets and 3-zone responsive UI provide better visual short-form output. |
| **6. Streamer Pinning (Name & Avatar)** | **Works** (`clipper/streamers.py:30-180`, `clipper/web/static/app.js:1750-1850`). Channel platform detection (YouTube/Twitch/Kick), avatar fetching, live viewer count, and `.live-ring` animation in `data/state.json`. | **Has** (`studio/live.py:50-110`). Channel bookmarks with platform icons and metadata polling. | **Keep ours**: Native lightweight persistence in `data/state.json` without requiring external database dependencies. |
| **7. AI Title, Caption, Hashtags & Thumbnail** | **Works** (`clipper/ai.py`, `clipper/thumbnail.py`). Generates hook titles, platform descriptions, viral hashtags with Gemini/OpenAI/Ollama and local heuristic fallback. Laplalcian sharpness frame extraction with badge overlay. | **Has** (`studio/brain.py`, `studio/render.py`). OpenAI/Anthropic prompt templates for titles/descriptions; thumbnail frame capture. | **Keep ours**: Local fallback ensures 100% offline functionality without API keys. |
| **8. Scheduling and Posting** | **Partial** (`clipper/youtube.py`). YouTube OAuth 2.0 desktop authorization, scheduled publish time, daily upload caps, and dry-run simulation mode. TikTok and Instagram targets are not yet implemented. | **Partly** (`studio/server.py:800-920`). Basic webhook/export triggers, but lacks official Instagram Graph / TikTok Content Posting API flows. | **Build new**: Build unified multi-platform queue and publisher with official platform APIs and manual download fallback. |
| **9. Health Checks** | **Works** (`clipper/health.py`, `clipper/api.py`). Real `/healthz` returning dependencies (FFmpeg, ffprobe, yt-dlp, Node.js), disk write check, free space, path safety, and startup logging. | **Partly** (`studio/server.py:90-110`). Basic ping/status check and model download verification. | **Keep ours**: Comprehensive diagnostic coverage meeting cloud and Kubernetes health probe standards. |
| **10. Gaming / GTA VI Mode** | **Missing** (Documented in `scratch/PeakCut/GAMING.md`). Custom keywords, mission cut detection, and GTA VI launch preset profiles are not yet implemented in `clipper/`. | **Has** (`GAMING.md`, `studio/brain.py`). Presets for high-action game events, mission completions, and launch presets. | **Port from PeakCut**: Port the preset definitions and gaming keyword trigger dictionaries from `scratch/PeakCut/GAMING.md`. |
| **11. Job Persistence** | **Works** (`clipper/jobs.py`). Disk-backed JSON job store (`data/jobs.json`) with atomic file writes and automatic startup reconciliation for interrupted jobs. | **Has** (`studio/jobs.py:50-200`, `studio/db.py`). SQLite/PostgreSQL persistent job queue with status recovery. | **Keep ours**: Lightweight, zero-dependency atomic JSON store matches our local, single-user desktop architecture. |

## Architectural Summary
- **Where Clipper leads**: Kinetic subtitle rendering (10 visual ASS presets), offline-first zero-key operation (RMS loudness + local heuristics), 5-factor mathematical virality ranking, and standards-compliant `/healthz` diagnostics.
- **Where PeakCut leads**: Gaming/GTA VI preset rules (`GAMING.md`) and multi-user account scaffolding (`studio/auth.py`).
- **Target Integration Plan for Stage B**:
  1. Port gaming keyword trigger profiles from `scratch/PeakCut/GAMING.md` into `clipper/candidate_picker.py`.
  2. Implement short staging directory for rendering (`C:\temp` / `tempfile`) before moving output into `data/out/`.
  3. Expand social posting to include Instagram / TikTok manual export bundles.
