## Top 10 Blockers

1. **Broken YouTube Test URL (Item 10)**: `https://youtu.be/CsWOUBuokjo` is unavailable / rate-limited (HTTP 429) on YouTube; requires updating test suite with a guaranteed stable public test video URL.
2. **Missing `docs/gap-analysis.md` (Item 8)**: Architectural documentation comparing features against PeakCut is absent from `docs/`.
3. **Missing `tests/run.py` Standalone Script (Item 6)**: The test suite currently requires direct `pytest` execution; a single entrypoint `tests/run.py` is expected by test runners.
4. **Missing `/healthz` Endpoint Alias (Item 7)**: Health diagnostics are currently served at `/api/health`, while external orchestrators and spec expect `/healthz`.
5. **In-Flight Jobs Lost on Server Restart (Item 39)**: Background jobs in `clipper/jobs.py` reside exclusively in memory (`_jobs = {}`); active jobs do not resume after restart.
6. **Missing In-App Developer Setup Wizards (Item 49)**: Google Cloud, Meta/Instagram, and TikTok Developer setup guides with redirect URI copy buttons are absent from the UI.
7. **Missing Calendar & Queue View (Item 51)**: Post scheduling relies on a modal; drag-and-drop schedule calendar and queue state timeline are missing.
8. **Missing Gaming / GTA VI Presets (Item 36)**: Presets from `GAMING.md` and game auto-detection are not implemented in the active pipeline.
9. **Missing Multi-Platform Posting (Item 47)**: Direct automated posting is currently restricted to YouTube OAuth; TikTok and Instagram targets are absent.
10. **Dual Frontend Artifact Contradiction (Item 70)**: `package.json`, `tailwind.config.js`, `components/`, and `lib/` coexist alongside the active vanilla frontend (`clipper/web/static/`), creating maintenance ambiguity.
